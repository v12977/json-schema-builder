# JSON Schema Builder 🧩

A dynamic React-based tool to visually build and preview JSON Schemas in real-time.

---

## 🔗 Live Demo

[Click here to view the hosted app](https://json-schema-builder-jade.vercel.app/)



---

## ✨ Features

- ➕ Add custom fields with types (string, number, boolean, object)
- 🖊️ Edit field names and types
- 📂 Nest fields inside objects (recursive nesting supported)
- 🗑️ Delete fields
- 🔄 Real-time JSON preview
- 💾 Download schema as `.json` file
- 📤 Upload schema and auto-generate form

---

## 🛠️ Tech Stack

- React (Create React App)
- Tailwind CSS
- JavaScript (ES6+)
